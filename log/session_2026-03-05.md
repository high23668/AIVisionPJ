## 発見したトラブルと解決策

### 1. Qwen3-VL 8B VRAM OOM
- **原因**: transformers 5.x が量子化前にbf16でGPUロードする
- **解決**: 4Bモデル (bfloat16) を使用 → 2.7GB VRAM で動作

### 2. DINOv3 GatedRepoError
- **原因**: HuggingFaceのモデルページで「Agree」していなかった
- **解決**: https://huggingface.co/facebook/dinov3-vitb16-pretrain-lvd1689m でアクセス申請

### 3. DINOv3 PCA可視化エラー (reshape)
- **原因**: 200パッチが正方形でない (14×14=196 ではない)
- **解決**: 因数分解ループで h=10, w=20 を動的計算

### 4. FoundationPose: libc10.so not found
- **解決**: `export LD_LIBRARY_PATH=/opt/conda/envs/my/lib/python3.8/site-packages/torch/lib:$LD_LIBRARY_PATH`

### 5. FoundationPose: debug_dir=None でエラー
- **解決**: `tempfile.mkdtemp()` を使用

## カメラを使った統合テスト (明日の後半)

```bash
# RealSenseで画像キャプチャ
python -c "
import pyrealsense2 as rs
import numpy as np
import cv2

pipeline = rs.pipeline()
config = rs.config()
config.enable_stream(rs.stream.color, 640, 480, rs.format.bgr8, 30)
config.enable_stream(rs.stream.depth, 640, 480, rs.format.z16, 30)
pipeline.start(config)

frames = pipeline.wait_for_frames()
color_frame = frames.get_color_frame()
depth_frame = frames.get_depth_frame()

color_image = np.asanyarray(color_frame.get_data())
depth_image = np.asanyarray(depth_frame.get_data())

cv2.imwrite('/home/vr01/AIVisionPJ/data/sample_images/realsense_rgb.png', color_image)
depth_meters = depth_image * pipeline.get_active_profile().get_stream(rs.stream.depth).as_video_stream_profile().get_intrinsics().depth_scale
np.save('/home/vr01/AIVisionPJ/data/sample_images/realsense_depth.npy', depth_meters)
cv2.imwrite('/home/vr01/AIVisionPJ/data/sample_images/realsense_depth_vis.png', (depth_image / 4096 * 255).astype(np.uint8))

pipeline.stop()
print('Saved rgb + depth')
"
```
