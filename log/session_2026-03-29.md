  -v $(pwd)/data/realsense_cup/mask.png:/data/mask.png \
  -v $(pwd)/data/realsense_cup/intrinsics.json:/data/intrinsics.json \

      --rgb /data/rgb.png \

### 1-5. ポーズ可視化

メッシュ頂点をカメラ行列K + 推定ポーズで画像に投影し、緑の点を描画。

```python
import numpy as np, cv2
from PIL import Image
import trimesh

mesh = trimesh.load('results/any6d_realsense/mesh.obj')
pose = np.loadtxt('results/any6d_realsense/pred_pose.txt')
K = np.loadtxt('results/any6d_realsense/K.txt')
img = cv2.imread('data/realsense_cup/rgb.png')

pts = mesh.vertices
n = len(pts)
pts_h = np.hstack([pts, np.ones((n, 1))])
cam = (pose[:3, :] @ pts_h.T).T
valid = cam[:, 2] > 0
cam = cam[valid]
px = cam[:, :2] / cam[:, 2:3]
uv = (K[:2, :2] @ px.T + K[:2, 2:3]).T.astype(int)
for u, v in uv:
    if 0 <= u < img.shape[1] and 0 <= v < img.shape[0]:
        cv2.circle(img, (u, v), 3, (0, 255, 0), -1)

Image.fromarray(cv2.cvtColor(img, cv2.COLOR_BGR2RGB)).save('/tmp/pose_overlay2.png')
```

- 出力: `results/any6d_realsense/pose_overlay.png`

## 3. 備考・注意点

- depth_scale: 0.001 (RealSense D435I, uint16 mm → float m)
- メッシュスケール: SF3D生出力は約90cm → scale=0.1 で9cm (実物に近い)
- SF3Dの単視点限界: 正面画像では奥行きが薄い (ペラペラ) メッシュになる
  - 45°斜め撮影の方が品質向上する可能性あり
- ポーズオーバーレイ: 緑の塊がコップ前面を覆う → 位置推定は妥当
  - メッシュが薄いためワイヤーフレーム的な表現にはならない
