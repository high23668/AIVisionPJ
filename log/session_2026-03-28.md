## 3. アーキテクチャ決定事項

**SF3D-Docker統合方針: 2ステップ分離 (Option B)**

- ホスト (.venv_3d): SF3D でメッシュ生成
- Docker (any6d:latest): Any6D + FoundationPose でポーズ推定
- 理由: 環境分離・デバッグ容易性・ROS2統合時の拡張性

**DockerイメージのInstantMesh pip installを削除**

- SF3D置換により不要。ソースコードは COPY . . で残存
- `sam2_instantmesh.py` の instantmesh import は軽量ユーティリティのみ (rembg, PIL)

## 4. 実行手順 (今後)

```bash
# Step 1: メッシュ生成 (ホスト, .venv_3d)
source .venv_3d/bin/activate
python scripts/any6d_generate_mesh.py \
  --image <anchor_image.png> \
  --output results/any6d/mesh.obj \
  [--mask <mask.png>]

# Step 2: ポーズ推定 (Docker)
docker run --rm --gpus all \
  -v $(pwd)/models/foundationpose/FoundationPose/weights:/foundationpose/weights \
  -v $(pwd)/results/any6d/mesh.obj:/input_mesh.obj \
  -v $(pwd)/models/any6d/run_demo.py:/run_demo.py \
  any6d:latest bash -c "
    source /opt/conda/etc/profile.d/conda.sh && conda activate Any6D
    python run_demo.py --mesh /input_mesh.obj
  "
```
