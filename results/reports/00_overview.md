## 1. なぜ透明物体の認識は難しいのか

### 1.1 通常の物体認識との違い

一般的な物体認識システムは、物体の「色」「テクスチャ（模様）」「形の輪郭」を手がかりに
動作している。しかし透明なガラスや樹脂シートは、これらの手がかりを持たない。

| 手がかり | 不透明物体 | 透明物体（ガラス・樹脂） |
|---|---|---|
| 固有の色 | あり | なし（背景色が透けて見える） |
| テクスチャ | あり | なし（表面に模様がない） |
| 輪郭 | 明確 | 不明確（背景と融合） |
| 深度センサ（赤外線） | 反射で計測できる | **透過してしまい計測不能** |

とくに深度センサ（RealSense等で使われる赤外線ステレオ方式）は、赤外線がガラスや薄い
樹脂を**素通り**するため、透明物体のある場所の距離情報が取得できない。
これが透明物体認識の最大の技術的障壁である。

### 1.2 本調査の対象ワーク

| ワーク | サイズ（目安） | 材質 | 難易度 |
|---|---|---|---|
| 透明グラス（コップ） | φ75 × H140 mm | ソーダライムガラス | 中（縁・反射・底の歪みが手がかりになる） |
| ガラス板 | 148 × 148 × 2.5 mm | ソーダライムガラス | 高（薄さゆえに輪郭が消えやすい） |
| 樹脂シート | 70 × 100 × 0.1 mm | PET樹脂 | 最高（正面から見ると完全に不可視） |

透明グラス（コップ）は **Any6D・ASGrasp の動作確認** および **3glass 比較実験** で使用した。
本概観レポートの定量評価（深度推定 RMSE・IoU・Z誤差）はガラス板・樹脂シートを主な対象とする。

### 1.3 本調査の目的

将来のロボットアームによるピッキング自動化を見据え、透明ワークの
**3次元位置・姿勢の取得**（6DoFポーズ推定）を目標とする。
その前段として、多数の最新AIモデルを系統的に評価し、どの技術が透明物体に
対して有効かを明らかにすることを本調査の目的とする。

## 3. 技術の分類と関係性

### 3.1 切り口①：タスク別（何を出力するか）

物体認識は単一の技術で完結するのではなく、複数の処理が連鎖するパイプラインとして
実現される。各モデルはこのパイプラインのいずれかのステージを担う。

2D技術（物体検出・セグメンテーション・VLM）も評価したが、ロボットアームによる
把持には**3次元の位置・姿勢情報**が不可欠である。3次元認識から把持計画に至るパイプライン
の一例は以下の通りである。

```
深度推定 → 3D検出 → ポーズ推定 → 把持計画
```

本調査では各ステージにおける代表的なモデルを選定し、透明ワークへの有効性を
比較評価した。各ステージと代表モデルの対応は以下の通りである。

| パイプラインステージ | 代表モデル | 出力 |
|---|---|---|
| 深度推定 | MoGe-2 / DA2 / Depth Pro / Foundation-Stereo | 距離マップ（mm/m単位） |
| 2D認識・セグメント | SAM3 / YOLO26 / DINOv3 / Qwen3-VL | マスク / BBox / 特徴量 |
| 3D検出 | Boxer | 3D回転バウンディングボックス（OBB） |
| ポーズ推定 | FP×CAD ※ / Any6D | 4×4 変換行列（位置＋姿勢） |
| 把持計画 | ASGrasp | 把持点座標・法線ベクトル |

※ FP = FoundationPose（NVIDIA）

### 3.2 切り口②：入力別（カメラの種類）

| 入力方式 | 必要なカメラ | 代表モデル | 透明物体への対応 |
|---|---|---|---|
| RGB 単眼 | 普通のカメラ1台 | DA2, MoGe-2, SAM3, YOLO26 等 | △（テクスチャ不要のモデルは有効） |
| RGB-D（RGB+深度） | RealSense等 | ASGrasp, Boxer, FP×CAD | △（深度が取れない部分が問題） |
| ステレオ（左右2眼） | ステレオカメラ | Foundation-Stereo | ×（テクスチャなし・IRで透過） |

> **補足**: RealSense D435i は「RGB-D カメラ」であり、RGB画像と赤外線ステレオによる
> 深度画像の両方を同時に取得できる。ただし透明物体では深度が正しく取れない。

### 3.3 切り口③：事前知識の必要性

モデルによって「使うために何を準備する必要があるか」が大きく異なる。
本調査のモデルはすべてゼロショット（追加学習なし）で動作するが、3D推定系は別途入力が必要となる。

| モデル | 役割 | 必要な準備物 |
|---|---|---|
| YOLO26 | 2D物体検出 | なし（既定クラス外はファインチューニングが必要） |
| SAM3 | 2Dセグメンテーション | テキストプロンプト（例: "glass plate"）のみ |
| DINOv3 | 視覚特徴抽出 | なし（参照画像があれば照合精度が向上） |
| Qwen3-VL | 視覚言語理解 | なし（自然言語プロンプトのみ） |
| DA2 / MoGe-2 / Depth Pro 等 | 単眼深度推定 | なし（壁校正のみで実距離への変換が可能） |
| Foundation-Stereo | ステレオ深度推定 | ステレオカメラ（左右2眼の同期撮影） |
| FP×CAD ※ | 6DoFポーズ推定 | **CADメッシュ**（.obj ファイル）＋ GT深度（校正用） |
| Any6D | 6DoFポーズ推定 | 参照画像1枚（ワンショット）＋ RGB-Dカメラ |
| ASGrasp | 把持点推定 | ステレオIR画像（RealSense のIR左右） |
| Boxer | 3D物体検出 | なし（RGB-D入力のみ） |

※ FP = FoundationPose（NVIDIA）

**ゼロショット**: 対象物の追加学習なしに、初見の物体を認識できる性質。
本調査のモデルはすべてゼロショットで動作する（対象物専用の学習データ収集・再学習は不要）。
唯一の例外は **Any6D** で、参照画像1枚（ワンショット）が必要だが、学習ではなく推論時の入力として使用する。

**主要な発見:**
- **Depth系**: MoGe-2 のみ全ワーク・全姿勢で安定。Metric3D v2 は透明物体を透過して背景と同一視するため完全に不適

## 4. 実験設計

### 4.1 Ground Truth（正解値）の取得方法

深度モデルの精度を評価するために、ワークの「真の距離」を測定する必要がある。
本調査では以下の方法を採用した。

```
通常撮影（透明状態）             青画用紙を貼って撮影
      ↓                               ↓
 深度センサで距離不明           深度センサが正しく計測できる
 （透過してしまう）             ↓
                          板面の平均距離 = Ground Truth Z
```

青画用紙（不透明）をワーク全面に貼ることで、赤外線を反射させて正確な距離を取得した。
この GT Z 値は **精度 ±2mm** 以内で測定できることを確認している。

### 4.2 深度校正方式

単眼深度モデルの出力はそのままではスケールが合わないため、実距離への変換が必要である。
本調査では2種類の校正方式を比較した。

| 方式 | 使う基準点 | 精度 | 準備コスト |
|---|---|---|---|
| **壁校正（1点校正）** | 壁面のみ | RMSE ~50mm | 低（専用マーカー不要） |
| **Affine校正（2点校正）** | 壁面 + GT Z | RMSE ~19〜34mm | 中（青画用紙が必要） |

**Affine校正の仕組み:**
`補正後の深度 = a × モデル出力 + b`
壁の距離と板面の GT Z という2点から係数 a（スケール）と b（オフセット）を決定する。
これにより単眼深度モデルの相対的な形状情報を実距離に対応させることができる。

**注意**: 板の距離と壁の距離が非常に近い場合（樹脂シート正面など）、
2点の差が小さすぎて校正が発散する問題が発生した（Affine校正崩壊）。

### 4.3 実験シーン

| シーン | ワーク | カメラ角度 | GT Z |
|---|---|---|---|
| glass_front | ガラス板 | 正面 | 383.6mm |
| glass_oblique | ガラス板 | 30°斜め | 377.0mm |
| resin_front | 樹脂シート | 正面 | 163.0mm |

### 5.1 単眼深度推定 — RMSE 比較

![RMSE比較](fig_depth_rmse.png)
*各深度モデルの板面 RMSE（GT Affine校正後）。棒グラフのないものは測定不可（深度崩壊）。

詳細な数値は [04_depth_mono.md](04_depth_mono.md) 参照。

### 5.2 透明物体セグメンテーション — SAM3 IoU

| ワーク | 正面 IoU | 斜め（30°）IoU | 改善率 |
|---|---|---|---|
| ガラス板 | 91.6% | 94.7% | +3.1pt |
| 樹脂シート | **12.8%（失敗）** | **92.2%（成功）** | +79.4pt |

**発見**: 樹脂シートを30°傾けると、表面反射が増大してSAM3が認識できるようになった。
これはプラスチック表面のBrewster角（~56°）に近づく方向の反射増大によるものと推察される。

| Any6D（SF3D+FP） | 全失敗（姿勢誤り） | 全失敗 |

## 6. 現時点の推奨パイプライン

ガラス板を対象とした場合の推奨構成を示す。

```
Step 1: 撮影
  RealSense D435i で RGB + IR ステレオ撮影

Step 2: マスク生成（どこにワークがあるか）
  SAM3 で透明ガラス板をセグメント
  → プロンプト "transparent glass" / IoU ~92%

Step 3: 深度推定（ワークまでの距離）
  MoGe-2（全ワーク対応）or DA2（ガラス板のみ高精度）
  → Affine校正で実距離に変換

Step 4: 6DoFポーズ推定
  FoundationPose × CAD メッシュ
  → GT深度 + CAD で Z誤差 +0.1mm 達成
```

**制約事項:**
- Step 3 の Affine 校正には GT Z（青画用紙測定）が必要
- CAD メッシュが必要（FoundationPose）
- 樹脂シートは正面撮影では全ステップで困難。斜め撮影（30°）が必要

| 課題 | 内容 | 有望なアプローチ |
|---|---|---|
| 樹脂シート正面の認識 | 正面では全モデル困難 | 偏光カメラ / 構造化光 / UV照明 |
| GT 校正の不要化 | 青画用紙測定を省略したい | ピクセルサイズ法（誤差~15mm）/ 既知サイズ物体 |
| 背景コンテキスト活用 | 背景物体で認識率向上を検証 | ChArUco背景でF-Stereo / SAM3 改善を検証予定 |
| 処理速度 | 現状はオフライン処理 | TensorRT最適化 / モデル軽量化 |
| ロボット統合 | ROS2 への組み込み | パイプライン確立後に実装 |

## 8. 用語集

| 用語 | 説明 |
|---|---|
| **6DoF ポーズ推定** | 物体の3次元位置（X/Y/Z）と向き（ロール/ピッチ/ヨー）の6自由度を推定すること |
| **RGB-D カメラ** | カラー画像（RGB）と距離画像（Depth）を同時に取得できるカメラ。RealSense D435i が代表例 |
| **RealSense** | Intel 製の深度センサ搭載カメラ。赤外線ステレオ方式で距離を計測する |
| **IR（赤外線）** | Infra-Red の略。深度センサが距離計測に使う不可視光。透明物体は透過してしまう |
| **CADメッシュ** | 3Dモデリングソフトで作成した物体の形状データ（.obj / .stl等）。FoundationPose の動作に必要 |
| **ゼロショット** | 対象物の追加学習なしに初見の物体を認識できる性質 |
| **ワンショット** | 参照画像1枚だけで物体を認識できる性質。Any6Dが相当 |
| **IoU** | Intersection over Union。セグメンテーションの精度指標。0〜1 の値で、1 が完全一致 |
| **RMSE** | Root Mean Square Error（二乗平均平方根誤差）。深度推定の誤差を mm 単位で表す |
| **GT（Ground Truth）** | 精度評価の基準となる「正解値」。本調査では青画用紙で計測した板面距離 |
| **Affine校正** | 深度モデルの相対出力を実距離に変換する2点校正方式（a × 出力 + b） |
| **FP** | FoundationPose（NVIDIA）の略称。本文書では FP×CAD の形で使用 |
| **OBB** | Oriented Bounding Box（回転バウンディングボックス）。軸に沿わない任意方向の直方体 |
| **VLM** | Vision-Language Model。画像と自然言語を組み合わせて推論するAIモデル |
| **ViT** | Vision Transformer。画像をパッチ分割してTransformerで処理する基盤アーキテクチャ |
| **BOP** | Benchmark for 6D Object Pose Estimation。ポーズ推定の国際ベンチマーク |
| **SF3D** | Stable Fast 3D（Stability AI製）。1枚の画像から3Dメッシュを生成するモデル |
| **SAM3** | Segment Anything Model v3（Meta製）。テキスト / 点 / BBoxプロンプトで領域抽出 |
| **Brewster角** | ガラス表面への入射光が最大偏光反射する角度（約56°）。樹脂シートの斜め撮影で有効性向上の要因 |
